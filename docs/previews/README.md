# 강화 연출 미리보기

> 진화 미리보기(받침대 위로 결과가 나무처럼 갈라지는 표시)는 `evolution-branch-preview.html`을 직접 열면 됩니다. 수치는 `scripts/lib/upgrade_branch_preview.lua`·`scripts/conch_blessing_highlight.lua`와 같고, 게임 안 확인은 `conch_test evolution`입니다. 시안을 고친 뒤에는 두 Lua 파일도 같은 값으로 맞춥니다.

`item-upgrade-player.html`을 직접 열면 재생됩니다. 서버와 인터넷은 필요하지 않습니다.
아이콘으로 항목을 선택하고, **전체 / 인게임 적용 / 보류**로 목록을 나눌 수 있습니다.
한글 검색, 시간 이동, 재생·일시 정지, 반복 및 효과음 설정을 지원합니다.

HTML은 연출 시안입니다. 아래 명령은 실제 원본 아이템을 생성하고, 소라고둥과 같은 강화 처리로 변환합니다.
보류 시안은 HTML에서만 재생되며, 게임에서는 기존 기본 강화 연출을 유지합니다.
HTML의 크로노스 보유 펫 선택은 예시 목록이며 실제 게임의 인벤토리와 연결되지 않습니다.

| 게임 콘솔 | 동작 |
| --- | --- |
| `conch_morph` | 실제 받침대 아이템으로 34종 강화 변환 보기 |
| `conch_morph liveeye` | 살아있는 눈 선택 (보류: 현재 기본 연출) |
| `conch_morph real_eyes` | 구피의 눈 → Real Eyes (기본 긍정 연출) |
| `conch_morph soflam` | SOFLAM 미사일 연출 |
| `conch_morph kronos` | 보유 펫이 토성 고리를 돌다 BFF로 합쳐져 크로노스 |
| `conch_morph time_tear` | 시간 = 연사 연출 (`timetear`도 가능) |
| `conch_morph list` | 항목 및 적용 상태 목록 |
| `conch_morph stop` | 종료 및 입력 복원 |

- **R**: 이전 미리보기 아이템을 정리하고 원본부터 다시 강화
- **← / ↑**: 이전 아이템, **→ / ↓**: 다음 아이템
- **Backspace**: 종료
- 화면 아래에 현재 항목, 적용 여부, 이전·다음 아이콘을 표시합니다.
- 실제 원본 받침대·장신구를 한 개 생성하고, 강화 전 연출 → 실제 아이템 변환 → 이름 표시 → 강화 후 연출을 거칩니다. 연출이 끝나도 결과 아이템은 화면에 남습니다. 명령은 선택한 강화 결과를 지정하며 소라고둥의 결과 추첨은 하지 않습니다.
- 받침대·그림자·장식은 게임이 계속 그립니다. 전용 연출은 실제 아이템 레이어만 그리며 원래 위치와 떠 있는 움직임을 따릅니다. 이전·다음·재생은 같은 자리를 유지합니다. REPENTOGON의 레이어 제어·프레임 조회 기능이 없거나 다른 모드의 스프라이트가 호환되지 않으면 기본 강화 연출로 돌아갑니다.
- 미리보기 아이템만 획득을 막고, 재생·항목 전환·종료 시 그 아이템과 해당 강화 작업만 정리합니다. 다른 받침대나 소지품은 바꾸지 않습니다. 강화 이펙트는 계속 전투 효과 없는 스프라이트를 사용합니다.
- 실제 강화와 변환 처리·타이밍은 같고, 대상·진행 상태·스프라이트는 각각 별도로 관리합니다. 실제 소라고둥의 강화·삭제 검색은 미리보기 아이템을 제외하며, 미리보기 전환·종료는 동시에 진행 중인 실제 강화를 취소하지 않습니다. 효과음은 한 번 재생한 뒤 자연스럽게 끝나게 하여 다른 강화나 게임 소리의 중지·볼륨을 건드리지 않습니다.
- 강화 대기부터 후속 연출이 끝날 때까지 해당 아이템의 강화 가능 색칠을 멈춥니다. 다른 아이템의 표시에는 영향을 주지 않습니다.
- 런은 재시작하지 않으며 게임 진행 자체를 정지시키지 않습니다. 방 이동 전에 미리보기 아이템을 정리하도록 REPENTOGON의 `MC_PRE_CHANGE_ROOM` 기능이 필요합니다.
- 방 이동·게임 종료·새 게임 시작·모드 재로드 시 종료하며, `conch_test` 실행 중에는 열리지 않습니다.
- 새 ANM2를 처음 적용하거나 수정한 뒤에는 게임을 완전히 재실행해야 합니다.

현재 적용 대상은 공허의 단검, 진, 크로노스, 돈 = 연사, 서리의 숨결, 화염의 숨결, SOFLAM, 편측무시,
시간 = 돈 패밀리어와 4종 장신구(시간 = 힘·연사·행운, 천사의 왕관)로 13종입니다.
나머지 22종(살아있는 눈, 아트로포스, 마이너스 4종 등)은 보류이며 게임에서는 기본 강화 연출을 사용합니다.

적용 연출은 HTML과 게임이 같은 기준으로 움직입니다. 변환 시점과 길이는 `scripts/upgrade_visual_catalog.lua`의 `impact`·`duration`을 양쪽이 함께 읽고, 효과음은 같은 프레임·볼륨·높이로 재생합니다. 게임에서 여러 샘플 중 하나를 무작위로 고르는 효과음(천둥, 서리, 미사일 발사·폭발, 천사 날개)은 HTML도 같은 샘플 묶음에서 무작위로 고릅니다. 실제 아이템은 한 프레임에 바뀌므로 HTML도 변환 순간 바로 전환하며, 게임은 변환 프레임 자체를 건너뛰지 않고 표시합니다.

시계는 아이템의 32×32px 영역 안에 들어가는 황동 테두리와 별도 바늘 스프라이트를 사용하며, 아이템 앞에서 한 바퀴 회전 후 사라집니다. 중앙은 투명해 아이템이 비칩니다.
시간 = 행운은 시계만 표시하며 위쪽에 초록색 원이나 잎을 추가하지 않습니다.
시간 아이템 4종은 모두 시간 = 연사와 같은 길이(변환 96틱, 전체 150틱)이고, 시계가 6시에서 12시까지 여섯 시간을 돕니다. 분침은 일정한 빠른 속도(프레임당 22.5도)로 여섯 바퀴를 돌고, 한 바퀴가 째깍 한 번입니다: 분침이 6을 지날 때 '째', 12에 닿을 때 '깍'이 8틱 간격으로 끊임없이 이어지고, 여섯 번째 '깍'과 12시가 변환 순간이고, 그 순간 괘종시계가 묵직하게 '댕~' 하고 12시를 칩니다(합성한 `Conch Upgrade Clock Bell`: 가벼운 종이 아니라 코일 공의 낮은 기본음(C3)과 금속 배음이 천천히 맥놀이하며 약 4.5초 울리고, 가죽 망치의 둔탁한 타격과 나무 케이스의 낮은 울림이 깔림; 바닐라에는 시계 타종음이 없음). '째'와 '깍'은 서로 다른 합성음(`Conch Upgrade Clock Tick`은 밝고 날카로운 딸깍, `Conch Upgrade Clock Tock`은 낮고 속이 빈 딸깍)입니다. 두 소리 모두 음이 있는 '뿅' 소리가 아니라 실제 기계식 시계처럼 팔레트가 탈진기 바퀴를 치고 몇 ms 뒤 바퀴가 떨어지며 나는 짧은 두 번의 딸깍과 금속·케이스 울림입니다.
천사의 왕관은 바닐라 후광이 내려오며 하얗게 정화된 뒤 빛줄기와 작은 BLING 반짝임 스프라이트로 마무리합니다. 빛이 내려친 뒤 약 1.5초에 걸쳐 흰색에서 원래 색으로 부드럽게 돌아오고, 색 복원을 마친 뒤 기본 픽업 표시로 넘깁니다. 변환 전 연출은 실제 아이템 식별 기준으로 정리하여 변환 후 연출과 겹치지 않게 합니다. 후광은 아이템 위에 작게 표시하며, 이미지 여백을 뺀 왕관 그림의 중심을 따릅니다.
SOFLAM은 아이템 뒤에 바닐라 조준선을 빨갛게 착색해 표시하는 순간 SOFLAM 아이템과 같은 조준 경고음(Doctor's Remote의 `SOUND_DR_REMOTE_WARNING`, 1초 동안 빠르게 삐삐거림)이 나고, 화면 위에서 꼬리 불꽃을 단 미사일이 떨어집니다(발사음 `SOUND_ROCKET_LAUNCH`). 실제 공격 엔티티를 떨어뜨리면 적 피해, 바위·똥·TNT 파괴, 비밀문 열림, 픽업 밀림 같은 게임플레이 효과가 생기므로 연출은 그림과 소리로만 재현합니다. 53틱에 아이템 바로 아래에서 폭발하며 `SOUND_ROCKET_EXPLOSION`(샘플 4종 중 무작위)이 납니다.
공허의 단검은 작은 검은 연기 18개가 아이템 앞에서 소용돌이치며 칼자루 아래의 보랏빛 공허 문양으로 모입니다. 모이는 동안 크기와 진하기를 거의 유지해 문양 위에서 덩어리로 계속 소용돌이치고, 변환 순간 3틱 안에 한꺼번에 사라집니다.
편측무시는 화면(시야)의 왼쪽 절반이 가운데에 24px 부드러운 가장자리를 두고 서서히 검게 변해(6~42틱) 완전히 검은 채로 변환(66틱)을 맞고, 변환 뒤 45틱 동안 서서히 다시 보입니다. 경계는 화면 가운데이며 효과음은 없습니다.

시간 아이템 4종(시간 = 돈, 시간 = 힘, 시간 = 연사, 시간 = 행운)은 모두 같은 시계 연출 하나를 씁니다. 시계 옆에 동전이나 힘 눈금 같은 다른 장식은 없습니다.
진은 방이 서서히 어두워지면서 아이템과 그 주변만 부드럽게 밝게 남습니다. 어둠은 약 1.7초 동안 그대로 유지되고, 70틱(2.3초)에 낙뢰가 칩니다(전체 127틱). 암막이 치는 순간부터 낮은 천둥(`SOUND_THUNDER`, 0.65배 높이)이 쿠르릉 깔리며 낙뢰 쪽으로 차오르고, 낙뢰 순간 바로 옆에 내리치는 "쾅"(콰직 하는 균열음 위로 묵직한 쿵, 굴러가는 잔향)이 나오며 변환되고, 그 순간 어둠이 완전히 걷힙니다. 완성된 진 아이템은 변환 즉시 게임의 기본 픽업 렌더로 넘기며, 주변 섬광이 끝날 때까지 숨겨 두지 않습니다. 고정된 번개 줄기(푸른 외곽 빛·흰 심·곁가지 하나)는 7틱 동안 보이고, 아이템 아래의 바닥 고리가 약 0.5초 동안 퍼지며 사라집니다. 짧은 섬광만 잦아들며 다시 어두워지지 않습니다. 낙뢰음은 이 프로젝트용으로 합성한 단일 샘플(`resources/sfx/conch_upgrade_thunder_strike.wav`, `content/sounds.xml`의 `Conch Upgrade Thunder Strike`)이라 게임과 HTML이 같은 소리를 냅니다. 바닐라 번개음(`SOUND_LIGHTBOLT`)의 날카로운 고음 지직거림은 쓰지 않습니다. 아스트로의 프로메테우스(어둠의 저주)와 달의 서(어두운 방과 달빛)를 참고했으며, 강화 연출 자체는 저주나 방 상태를 바꾸지 않아 중단·방 이동 때 남지 않습니다.
서리·화염 브레스는 촛심에서 시작한 불꽃의 위쪽 끝을 고정하고 아래로 커져 촛불을 감싼 뒤, 불꽃 모양 아이템으로 잦아듭니다. 화염은 바닐라 주황 불꽃(`effect_005_fire.png`), 서리는 푸른 불꽃(`effect_005_fire_blue.png`)을 씁니다.
비 연출의 바닥 침수 표시는 REPENTOGON의 매 프레임 `MC_PRE_BACKDROP_RENDER_WATER` 콜백이 있는 경우에만 표시합니다.
콜백이 없는 게임에서는 비와 물결을 표시하며 실제 방 지형은 바꾸지 않습니다.
시간 = 연사는 비 없이 시계만 나옵니다. 돈 = 연사는 빗방울이 닿을 때마다 파래지는 속도가 크게 올라가고, 빗방울 사이에도 색 변화가 이어집니다. 색 농도를 계단식으로 바꾸지 않습니다. 변환 순간에는 결과 아이템도 원래 아이템이 끝난 만큼 젖은 색으로 시작해 45틱 동안 서서히 말라 자기 색으로 돌아오며, 착색은 아이템 레이어를 그리는 동안에만 적용합니다. 원본 색상·투명도·크기는 독립된 값으로 보관하며, 각 렌더 직후와 완료·중단 시 복원합니다.
비 연출은 변환 3.2초(96틱), 전체 5.8초(174틱)로 색이 바뀔 시간을 충분히 줍니다. 빗방울 다섯 개가 16틱 간격으로 아이템에 떨어지며 파랗게 물들입니다. 바닐라에는 빗소리 효과음이 없어서(Downpour의 빗소리는 배경음악), 이 프로젝트용으로 합성한 빗소리(`Conch Upgrade Rain`)가 비가 내리기 시작할 때 깔립니다. 침수는 0.6초부터 차올라 마지막 20틱 동안 빠지는 시각 효과이며, 비도 마지막 24틱 동안 그칩니다. 빗방울 28개(큰 방은 바닥 면적에 비례해 늘림) 중 셋에 하나는 아이템 앞에서 떨어지고, 바닥에는 바닐라 물결(`1000.133_water ripple.anm2`)이 생깁니다. L자 방의 빈 공간에는 떨어지지 않습니다.
크로노스는 보유 펫 스프라이트 복사본을 최대 3개 사용하며 실제 펫에는 영향을 주지 않습니다. 복사본은 펫 본래 속도로 계속 움직입니다.
크로노스의 적용 연출은 **토성 고리**입니다. MattPack의 범용 변환이 약 2.8초에 걸쳐 아이템을 하얗게 만든 뒤 바꾸고 색을 서서히 되돌리는 것처럼, 보면서 녹아들 시간을 두는 긴 연출입니다(변환 120틱 = 4.0초, 전체 170틱 = 5.7초, 카탈로그 값).
- 펫은 처음부터 궤도 위의 자기 자리에서, 궤도를 따라 천천히 돌면서 하나씩 0.8초에 걸쳐 투명도와 크기가 커지며 나타납니다.
- 회전이 점점 빨라지고 반지름이 48px에서 14px까지 줄어 아이템에 바짝 붙습니다. 궤도 뒤쪽을 지날 때는 아이템 뒤에, 앞쪽을 지날 때는 앞에 그립니다.
- 크로노스 아이콘은 토성 기호(♄)를 시계 방향으로 232° 돌린 그림이므로, 고리 전체와 앞쪽 반도 같은 232°만큼 돌렸습니다. 고리는 오른쪽 아래로 36° 기울고, 위쪽 반이 아이템 앞을 지나 아래에서 올려다본 토성처럼 보입니다.
- 2.3초부터 아이템이 점점 하얗게 차오르고(흰색으로 보간), 변환 직전에 완전히 하얘집니다.
- 펫이 금빛 고리 하나로 합쳐지며 반짝인 뒤 한 박자 멈추고, 고리가 수축하는 순간 변환되며 크로노스가 살짝 찌그러지며 내려앉습니다.
- 결과 아이템은 1.5초에 걸쳐 흰색에서 원래 색으로 돌아옵니다.
- 효과음은 회전 가속에 Mother의 회전 공격 시작음(`SOUND_MOTHER_SPIN_START`, 0.5), 변환에 크로노스가 실제로 펫을 흡수할 때 나는 `SOUND_SUMMONSOUND`(0.6)이며, 변환 순간 화면이 짧게 흔들립니다. 처음 고른 회전음·반짝임은 원본이 너무 작아(-20dB) 게임에서 들리지 않았습니다.
예전 삼키기 연출과 그 입 그림(`conch_upgrade_maw*`)은 이 결정으로 게임과 Workshop 패키지에서 뺐습니다. 생성 기록은 `kronos-mouth-prompt.txt`와 git 기록에 남아 있습니다.
HTML 크로노스 화면의 연출 버튼으로 다른 시안 3종을 비교할 수 있습니다. 게임에는 **토성 고리**만 들어가 있습니다.
- **낫질**: 펫이 BFF 주위로 모이고, 금빛 낫(결과 아이템 그림)이 떠올라 한 번 휘두르며 잔상 호를 남깁니다. 베인 펫은 금가루가 되어 낫으로 빨려 들고, BFF는 두 쪽으로 갈라져 떨어집니다. 낫이 받침대에 꽂히는 53틱에 변환되며 찌그러짐·흔들림이 있습니다. 효과음은 Death의 낫 소환, 칼 회전, 삽 떨어지는 소리입니다.
- **가루 흡수**: 실제 크로노스 흡수 연출처럼 펫 그림의 2×2 픽셀 알갱이가 위쪽부터 떨어져 BFF로 소용돌이칩니다. 마지막에 BFF도 부서져 돌다가 크로노스 그림의 픽셀 자리로 모입니다. 효과음은 게임플레이 흡수와 같은 `SOUND_VAMP_GULP`·`SOUND_SUMMONSOUND`입니다.
- **타르타로스 구멍**: 받침대 앞 바닥에 구멍이 열리고(실제 받침대는 그대로), 펫이 하나씩 뛰어들고 BFF도 받침대에서 뛰어내려 빠집니다. 구멍 속이 붉게 맥동한 뒤 낫이 솟구쳐 받침대 위로 착지합니다. 게임에 적용하면 구멍은 엔티티보다 먼저 그려지는 바닥 단계에 그립니다.
시계 부품 PNG도 이 프로젝트용으로 생성했으며, 테두리·긴 바늘·짧은 바늘을 ANM2로 분리합니다. 생성 요청은 `clock-art-prompt.txt`에 보관합니다.
펫이 없을 때만 예시 펫을 무작위로 고릅니다. 콘솔 미리보기는 1번 플레이어를 기준으로 합니다.
현재 Magic Conch의 전역 콜백은 사용자를 전달하지 않으므로, 협동 실제 강화에서는 소유자를 추측해 펫을 가져오지 않고 펫 없는 토성 고리 연출만 표시합니다. `conch_morph`는 1번 플레이어를 명시적으로 전달합니다.
REPENTOGON의 `Sprite:Copy`가 없는 구버전은 펫의 원래 ANM2 포즈를 복원하므로 동적으로 교체한 시트까지 복사하지는 못합니다.

## 관리 및 검증

- 적용 목록: `scripts/upgrade_visual_catalog.lua`
- HTML 상태 동기화: `python sync_upgrade_preview.py` (`--check`로 일치 검사)
- 효과음 크기·일치 검사: `python -m unittest tests.test_upgrade_sound_levels` (모든 강화음이 볼륨 1 이하에서 -18dB 이상으로 들리는지, HTML이 같은 소리를 같은 볼륨·높이로 트는지)
- 런타임 보조 이미지/ANM2·진 낙뢰음 재생성: `python generate_upgrade_visual_assets.py` (`content/sounds.xml`을 처음 적용하거나 바꾼 뒤에는 게임 완전 재실행)
- 오프라인 검사: `python -m unittest discover -s tests -p test_morph_viewer.py -v`, 프레임별 연출 계약은 `python -m unittest discover -s tests -p test_upgrade_presentations.py -v`
- 게임 자동 검사: `conch_test morph` (적용 연출 13종 + 기본 애니메이션 3종, 효과음 실제 재생·프레임·색 복원; `conch_test morph kronos`처럼 개별 실행)
- HTML 동작·Canvas 검사: `node tests/check_upgrade_preview.cjs` (`@napi-rs/canvas` 필요, 저장소 루트에서 실행; 브라우저 레이아웃 검사와는 별개)
- 실제 게임 검증: 각 연출, 재시작·이동 키, 일시 정지, 방 이동, 실제 Magic Conch 강화 전환을 확인하고 `log.txt`의 `[ConchMorph]` 및 리소스 오류 확인
- `[ConchMorph] DISPLAY`는 연출 종료 후 실제 픽업의 투명도·크기·레이어 표시·프레임 유무를 한 번 기록합니다. `MORPH`는 변환 완료만 뜻하며, `DISPLAY`도 화면의 최종 픽셀을 검증한 결과는 아닙니다. 아이템을 집어 들어 표시 프레임이 사라진 경우에는 강화 연출을 정리하고 게임의 획득 애니메이션을 유지합니다.

오프라인 Lua 더블·Canvas 검사는 실제 엔진 화면 확인을 대신하지 않습니다.
이 폴더는 Workshop 패키지에 포함되지 않습니다. main 푸시는 위키 갱신 알림을 보낼 수 있지만,
Workshop 업로드는 별도 수동 워크플로로만 실행됩니다.
