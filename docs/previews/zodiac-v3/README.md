# 십이지 아이콘 3차 시안

2026-10-24. 2차 시안에 대한 사용자 요청인 더 짙은 테두리, 산군의 위엄, 가리지 않은 토끼 얼굴, 전체 수호신의 무게감을 반영한 콘셉트 시안이다.

- 공통: 외곽선과 주요 내부 경계를 불투명한 깊은 검정으로 변경. 기존의 단순한 32×32 아이템 언어를 유지하면서 눈꺼풀·시선·명도 구획을 정리했다.
- 산군: 큰 둥근 포효 입을 없애고 넓은 이마와 턱, 절제된 좁은 눈, 닫힌 입으로 다시 구성했다.
- 토끼: 두 귀를 세우고 얼굴과 턱을 드러냈다. 간은 아랫배의 5픽셀 높이 영역으로 줄여 배치했다.
- 나머지 열 종: 기존 네이티브 원본의 실루엣과 모티브를 유지하면서 눈과 그림자, 일부 색을 직접 수정했다. 위엄을 위해 장식이나 효과를 추가하지 않았다.

`zodiac-overview.png`는 5배 최근접 확대와 1배 크기를 함께 보여 준다. `zodiac-dark.png`는 어두운 배경의 4배 확대와 1배 크기다. `icons/`에 투명 32×32 PNG 12개를 저장했고, `pixels.json`이 최종 픽셀 원본이다. `render.py`는 그 격자만 읽어 아이콘과 비교표를 다시 만든다. `validation.json`은 크기·색 수·경계·직접 수정 내역을 기록한다.

산군과 토끼는 **내장 image_gen**으로 수정 원안을 만든 뒤, 네이티브 격자에서 직접 정리했다. 두 프롬프트는 `prompts.json`, 생성 원안은 `drafts/`에 있다. 나머지는 이미 편집 가능한 `../zodiac-v2/pixels.json`의 네이티브 픽셀을 수정했다. 이 폴더의 최종 그림은 큰 생성 이미지를 자동 축소만 한 결과가 아니다.

재출력: 저장소 루트에서 `python docs/previews/zodiac-v3/render.py`.

2차 시안은 비교를 위해 보존했다. 런타임 아이콘과 게임 효과는 교체하지 않았으며, 화풍과 콘셉트는 사용자 검토 단계다. 재사용할 기준은 `../../isaac_item_sprite_study.md`와 루트 `AGENTS.md`의 Item Sprite Style에 기록했다.
