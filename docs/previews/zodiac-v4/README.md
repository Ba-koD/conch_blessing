# 십이지 아이콘 4차 시안 — 굵은 윤곽선

2026-10-24. 사용자 요청에 따라 12개 모두 바깥 윤곽선의 실제 두께를 늘렸다. 3차의 편집 가능한 `pixels.json`을 기준으로 외곽에 검정 1픽셀을 보강하여 주된 경계를 약 2픽셀로 만들었다. 이미 굵은 작은 접합부는 더 두꺼울 수 있다.

- 기존 눈·입·털 줄무늬와 모든 불투명 픽셀의 색·위치는 그대로 유지했다.
- 뿔·귀·팔다리 사이의 좁은 투명 틈과 내부 구멍은 보존했다.
- 32×32 캔버스의 바깥 1픽셀은 투명하게 유지했다. 토끼 귀 끝과 몸 아래처럼 이미 여백에 가까운 곳은 캔버스 밖으로 확장하지 않았다.
- 산군의 넓은 얼굴과 절제된 눈매, 드러난 토끼 얼굴과 낮게 놓인 간을 유지했다.

`pixels.json`이 최종 편집 원본이다. `outline_added_pixels`는 3차에 추가한 검정 픽셀의 좌표다. `icons/`에 투명 32×32 PNG 12개가 있으며, `render.py`는 격자에서 PNG와 비교표를 출력한다. 새 이미지 생성이나 자동 축소는 사용하지 않았다.

`zodiac-overview.png`: 5배 최근접 확대와 실제 크기. `zodiac-dark.png`: 어두운 배경. `zodiac-comparison.png`: 각 칸에서 왼쪽 3차 / 오른쪽 4차, 동일한 4배 확대와 실제 크기. `validation.json`: 크기, 색 수, 경계, 추가 픽셀 수, 기존 픽셀 및 투명 여백 보존 검사.

재출력: 저장소 루트에서 `python docs/previews/zodiac-v4/render.py`.

3차 시안은 비교용으로 보존했다. 이후 사용자 적용 요청에 따라 이 폴더의 12개 아이콘을 `resources/gfx/items/collectibles/<동물 영문명>.png`에 복사하여 ItemData에 연결했다. 그림 적용은 각 아이템의 효과 구현 완료를 뜻하지 않는다.
