# 적용 확정 스프라이트

2026-10-24 사용자 최종 결정에 따라 적용한 47종이다.

- 티르핑, 봉인된 마검, 경구형 스테로이드, 적사단지는 최초 런타임 원본으로 유지한다. 이 네 종의 모든 새 시안은 적용하지 않는다.
- 나머지는 앞서 지시된 선택을 유지한다. 영원한 불꽃 새 디자인, 원본 기반 주사기와 벨트 명도 수정, 선택한 십이지와 정면 백구·양, Perfection 기반 F-/C-/B-/A- 등을 포함한다.
- 실제로 원본과 다른 것은 19종이며, 나머지 28종은 원본 PNG와 바이트 단위로 같다.

`selection.json`은 원본 Git 리비전, 원본·선택본 SHA-256, 런타임 경로와 선택 이유를 기록한다. 적용 PNG는 `resources/gfx/items/`에만 보관하며, 변경 전 PNG는 기록된 Git 리비전에서 읽는다. 중복 아이콘 폴더와 폐기한 중간 시안은 정리했다.

`python docs/previews/resprite-final/verify_selection.py`로 47종의 적용본·원본 해시를 확인한다. `python docs/previews/resprite-final/render.py`는 Git 원본과 실제 런타임 PNG로 비교본을 재생성한다. Pillow와 Windows 맑은 고딕 폰트, 원본 리비전이 포함된 Git 이력이 필요하다.
