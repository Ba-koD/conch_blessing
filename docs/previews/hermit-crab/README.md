# 소라게 패밀리어 · 적용된 정면 스프라이트

2026-11-09. **사용자 요청으로 로컬 게임 파일에 적용했다.** 정면 껍데기 수정·BFFS 소지 개수별 자세·걷기 모션을 반영하고, 장신구를 직전 미리보기의 1.5배로 표시한다. 게임 재시작 후 화면 확인은 아직 하지 않았다. 창작마당 업로드와 커밋은 이번 작업에 포함하지 않는다.

## 적용 모습

- 기본형은 32×32, BFFS는 승인된 48×48 원본 프레임을 사용한다. BFFS 몸집이 이미 그림에 반영되어 있으므로 추가 1.25배 확대를 중복하지 않는다.
- 정면만 사용한다. 기본형은 눈 아래 중앙에 한 개를 들며, BFFS는 빈 집게를 중앙에 두고 장신구가 있는 집게만 올린다.
- 다리 세 쌍이 번갈아 디디는 8단계 걷기는 이동할 때만 재생된다. 정지하면 첫 자세로 돌아온다. 게임의 30 FPS 기준 단계당 3틱, 100ms이며 검토 GIF도 같은 속도다.
- 장신구는 원본 PNG를 그대로 사용하며 기본형 56.25%, BFFS 75%로 표시한다. 직전 시안 37.5%·50%에 각각 1.5를 곱한 값이다.
- 기본형은 장신구 윗끝을 눈 바로 아래(32px 프레임 20행)에 맞춰 집게 사이에 든다. 2026-11-09 사용자 지적(발 아래로 처짐)으로 올렸으며, 작은 장신구는 손끝(28행 아래끝)에 놓인다. 눈을 가리거나 확대 배율을 줄이지 않는다.
- 몸통 → 실제 장신구 → 앞쪽 손가락 순서로 그린다. 세 요소의 걷기 단계가 같고, 한 프레임에서 몸통 자세와 소지 목록이 어긋나지 않게 한다.

## 원본과 출력

`author.lua`가 실제 격자에서 그린 Aseprite 원본과 5종×8프레임 시트를 작성한다. 기본형은 48×48 공통 셀의 (8,12)에 크기 변경 없이 놓인다. 본체와 앞쪽 손가락은 별도 PNG이며 0/255 알파만 사용한다. Aseprite 마지막 두 레이어는 축소하지 않은 바닐라 예시 장신구 참고용으로 숨겨져 있다.

| 파일 | 내용 |
| --- | --- |
| `hermit_crab_proposals.aseprite` | 네이티브 편집 원본: 40프레임, 정면 걷기 태그 5개, 레이어 8개 (숨김 바닐라 참고 레이어가 있어 저장소 밖, `author.lua`가 다시 만듦) |
| `directions_sheet.png` | 적용 본체 시트 384×240. 정면만 포함, 가로 8단계·세로 기본 빈손/한 개/BFFS 빈손/한 개/두 개 |
| `grip_sheet.png` | 같은 셀 배치의 앞쪽 손가락 |
| `attachments.tsv` | 종류·단계·슬롯 중심/아래끝/배율/눈 아래 한계의 원본 자료 |

| `bffs-empty.png`, `bffs-one.png`, `bffs-claws.png` | BFFS 0/1/2개 정지 본체 |
| `comparison.png`, `bffs-comparison.png`, `trinket-check.png` | 현재 적용 파일 기준 정면·소지 자세·실제 원본 장신구 비교 (바닐라 장신구가 합성되어 저장소에는 넣지 않음, `preview.py`로 다시 만듦) |

| `preview.py` | 원본 장신구를 별도로 합성하는 검토판 작성 도구 |

원본 예시 장신구는 읽기 전용 추출 경로 `../../extracted_resources/resources/gfx/items/trinkets/`의 `trinket_035_curvedhorn.png`, `trinket_001_swallowedpenny.png`다. Swallowed Penny의 하늘색 물방울과 반투명 픽셀은 원본에 있다. 검토판의 1배 그림은 작은 표시 크기의 가독성 확인용이며 게임 캡처가 아니다.

저장소 루트의 `generate_hermit_crab_assets.py`는 완성 시트를 다시 그리거나 축소하지 않고 런타임 경로로 복사하며 ANM2와 `hermit_crab_visuals.lua`를 함께 생성한다. 소라게 수집 아이템 아이콘은 독립적으로 유지한다. 아트 수정 후 Aseprite의 `author.lua`에 `root=저장소경로`를 주어 실행하고, 포장 도구와 `preview.py`를 순서대로 실행한다. `generate_hermit_crab_assets.py --check`는 재생성 결과와 현재 게임 파일의 일치를 읽기 전용으로 확인한다.

## 확인과 한계

15개 소라게 오프라인 검사는 기존 소지·교체·반환·흡수 동작과 새 정면 걷기/정지, BFFS 자세, 정확한 1.5배 배율, 장신구 원본 경로, 몸통-슬롯-손가락 단계 일치, 생성기가 미리 잰 장신구 불투명 경계로 정렬(게임의 GetTexel은 알파를 0으로만 읽어 쓰지 않음, 2026-11-09 측정), 생성 파일 일치를 확인한다. 이 검사는 엔진 대역을 사용하므로 실제 게임 화면을 검증한 결과는 아니다. PNG/ANM2 변경을 읽으려면 게임을 완전히 재시작해야 한다.
