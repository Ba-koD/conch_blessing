# 십이지 아이콘 2차 시안

2026-10-24. 첫 생성 시안은 사용자 요청으로 폐기했다. 이 폴더는 바닐라와 설치된 모드의 실제 아이템 PNG를 관찰한 뒤 다시 만든 **콘셉트 검토용** 12종이다. 게임 적용이나 콘셉트 확정을 뜻하지 않는다.

- 관찰 근거와 재사용할 화풍 규칙: `../../isaac_item_sprite_study.md`.
- `zodiac-overview.png`: 정확한 32×32 아이콘의 5배 최근접 확대와 원래 크기. 순서: 자축인묘 / 진사오미 / 신유술해.
- `zodiac-dark.png`: 어두운 배경에서 4배 확대와 원래 크기.
- `icons/01-rat.png` … `icons/12-pig.png`: 투명 PNG 12개, 모두 32×32. 실제 사용하는 불투명 색은 각각 5–7색, 알파는 0/255.
- `pixels.json`: 최종 네이티브 격자, 팔레트와 아이콘별 직접 정리 내역. 앞으로 픽셀을 고칠 때의 원본이다.
- `render.py`: `pixels.json`만 읽어 PNG와 비교표를 다시 만든다. 생성 이미지를 축소하거나 읽지 않는다. Pillow와 Windows의 맑은 고딕을 사용한다.
- `drafts/`: 새로 만든 생성 원안 12개. 실제 픽셀 원본과 구별하며, 최종 에지·색·눈·소품 위치는 `pixels.json`을 따른다.
- `prompts.json`: 사용한 최종 프롬프트 12개와 원안의 출처. **내장 image_gen**을 사용했으며 CLI/API 대체 모드는 사용하지 않았다. 입력은 이 프로젝트의 `dragon.png`와 바닐라 관찰표였다. 타 모드의 아트워크 자체는 생성 입력이나 저장소 산출물로 복사하지 않았다.
- `validation.json`: 크기, 색 수, 경계와 직접 정리 내역의 기록. 수치 검사는 사용자 화풍 승인을 대신하지 않는다.

생성 원안의 구도를 등록한 뒤 네이티브 격자에서 직접 눈·코·입·소품의 경계와 제한 팔레트를 고쳤다. 예를 들어 뱀의 목을 검은 덩어리에서 녹색 면으로 연결하고, 돼지 몸의 밝은 색 얼룩을 지우고, 토끼의 간과 원숭이의 손/탄 겹침을 다시 그렸다. 자동 축소만 한 결과가 아니다.

재출력: 저장소 루트에서 `python docs/previews/zodiac-v2/render.py`.

기존 `resources/gfx/items/collectibles/dragon.png`와 다른 런타임 파일은 교체하지 않았다. 미(양)의 해태 연결 등 미확정 콘셉트는 계속 `../../zodiac_concepts.md`를 따른다.
