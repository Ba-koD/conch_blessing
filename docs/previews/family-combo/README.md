# Family Combo · 패밀리 세트

2026-11-08. 사용자가 접시 위에 담긴 모습이어야 한다고 정정했다. 기존 하단의 일자 잘림을 없애고, 패밀리어의 아래쪽 실루엣을 접시 안쪽 곡선에 맞췄다. 승인된 접시 바탕과 앞 테두리의 그림은 유지하며, 기존 접시의 양옆 곡선을 전경으로 드러내 받침이 이어지도록 했다. 작은 일반 미니 아이작을 위·안쪽으로 옮기고 바비와 매기의 기울기·앞뒤 순서를 조정해 눈·입은 테두리에 가리지 않게 했다.

승인된 흰 접시는 그대로다. 원본 크기·색·방향 프레임을 유지하며 회전만 허용 범위에 추가했다. Aseprite의 실제 32×32 캔버스에서 최근접 표본으로 배치하므로 부드러운 보간이나 축소가 없다. 회전 때문에 픽셀 배열과 일부 픽셀의 반복/생략은 생긴다. **회전 전후 모든 픽셀이 일대일로 같다는 뜻은 아니다.** 눈·입의 식별 획과 얼굴 가림은 별도로 확인했다.

## 출처와 배치

원본은 게임에서 추출한 `../../extracted_resources/resources/gfx/familiar/`다. 아래 좌표는 회전 중심의 배치 좌표이며, 양수 각도는 시계 방향이다. 큰 프레임의 기준 중심은 (15.5,10), 작은 프레임은 (7.5,6.5)다.

| 개체 | 원본 PNG | 중심 | 기울기 |
| --- | --- | --- | --- |
| 고스트 베이비 | `familiar_shooters_09_ghostbaby.png` | (11,6) | -7° |
| 브라더 바비 | `familiar_shooters_01_brotherbobby.png` | (7,14) | -19° |

| 미니 아이작 검은형 | `familiar_minisaac_black.png` | (6,22) | +25° |
| 미니 아이작 | `familiar_minisaac.png` | (25,20) | +15° |

고스트는 `IdleSide`의 (64,0,32,32), 다른 큰 패밀리어는 `IdleDown`의 (0,0,32,32)를 사용한다. 머리는 y=0..16, 몸통은 y=17..31로 분리하고 동일한 중심으로 기울인다. 미니 아이작은 `HeadDown`의 (0,0,16,16), `WalkDown`의 (0,16,16,16)을 사용한다. ANM2의 피벗 관계에 따라 몸통의 기본 위치는 머리보다 2픽셀 아래다.

모든 몸통을 얼굴 아래에 놓는다. 머리 레이어는 뒤에서부터 매기 → 일반 미니 아이작 → 로튼 → 고스트 → 검은 미니 아이작 → 바비다. y=23부터 양옆을 접시의 안쪽 곡선에 맞춰 가리고, y=28부터는 기존 앞 테두리 뒤로 들어간다. 편집 원본은 원래 접시 2개, 접시 바탕에서 가져온 전경 곡선 1개, 머리 6개, 몸통 6개의 15개 레이어다. 원본 자산 재사용은 사용자가 직접 요청했으며, 다른 모드 자산은 가져오지 않았다.

## 확인

- 두 접시 레이어의 2,048개 픽셀 위치·불투명도·합성 모드가 직전 적용본과 같다.
- 회전 후 눈·입의 식별 획에 해당하는 176개 표본이 위쪽 레이어나 접시에 가리지 않으며, 해당 원본 색과 알파를 유지한다. 고스트의 알파는 166이다. 회전 전후 얼굴 전체의 픽셀 동일성을 뜻하지 않는다.
- 머리의 불투명 부분이 캔버스 좌우·윗면 밖으로 잘리지 않는다. 네 모서리는 투명하고, 아래쪽 몸통/턱 가장자리는 접시 뒤로 들어간다.
- 네이티브 32×32에서 원래의 꽉 찬 구도를 유지하면서, 앞쪽 내용물이 접시의 하단 바깥으로 튀어나오지 않도록 했다. 실제 크기 및 정수 확대에서 접시와 내용물의 연결을 검토했다.
- 실제 바닐라 Binge Eater와 Epiphany Dad's Toolbox를 같은 1배·7배 배율로 비교했다. 참고판과 검사 기록은 저장소 밖 `C:/Users/rudgh/AppData/Local/Aseprite-build/family-combo-plated-contact/`에 있다.

## 파일과 적용

| 파일 | 내용 |
| --- | --- |
| `author.lua` | Aseprite 원본 작성. `root=저장소경로` 인자와 추출한 바닐라 PNG 필요 |

| `comparison.png` | 직전 적용본과 접시 안으로 담은 구도 비교 |
| `previous.png` | 이번 수정 직전의 적용본 한 장 |

런타임 파일은 `resources/gfx/items/collectibles/kids_menu.png`다. `generate_xml.py`로 사망 화면을, `sync_upgrade_preview.py`로 강화 미리보기를 갱신한다.

설명·이름·아이템 번호·효과·저장 키는 이번에 바꾸지 않았다. 한국어 EID는 “모든 아이템에 패밀리어 회전 배열을 추가하고 1초마다 전환되며 두 아이템 중 하나를 선택할 수 있습니다.”를 유지한다. 설명/동작 변경이 없으므로 런을 초기화하는 게임 내 설명 검사는 반복하지 않는다. 새 스프라이트의 게임 내 시각 확인은 사용자가 게임을 완전히 재시작한 뒤 진행해야 한다.
