# Conch's Blessing - RNG expected values

Generated by `rng_report.py` (seed 20260903). Constants are read from the Lua
sources at generation time; every figure cites the line it came from.

Closed-form results are exact arithmetic and use no sampling. Only the
distribution tables are sampled, at 200,000 draws each.

## 1. Per-roll stat multiplier

`value = math.floor((math.random() * span + MIN) * 100) / 100`

Truncation to 2 decimals makes this a discrete uniform, so the mean is
`(min + max - 0.01) / 2` - a hundredth below the midpoint, not the midpoint.

## 2. Stacking

Rolls are registered one per stack with `SetItemAdditiveMultiplier`
(`scripts/items/collectibles/oral_steroids.lua:30`).
Despite the name that call accumulates: StatsAPI stores `cumulative += value - 1`
and applies `effectiveM = 1 + cumulative`. So the applied total is

    total = 1 + sum(m_i - 1)

which is additive, matching the EID text.

> The `totalDamage = totalDamage * m` product in each item file is **dead**: it is
> computed, clamped to the per-item minimum, formatted into a debug log and then
> discarded. Nothing reads it; the applied floor below is what protects the
> value.

## 7. A- stat split

3 uniform weights are normalised and scale the budget left after the per-stat
minimum: `stat = 0.8 + w_i/sum(w) * (4 - 3*0.8)` (`scripts/items/trinkets/a_minus.lua:6`).
By symmetry each share averages `1/3`, so every stat has the same mean.

| Luck | **1.3333** | 1.3342 | 1.334 | 0.800 - 2.394 |

The sum is always exactly 4; the per-stat bound is [0.8, 2.4].
