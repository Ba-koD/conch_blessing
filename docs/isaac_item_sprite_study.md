## 십이지 재설계에 적용할 규칙

1. 실제 32×32 안에서 형태를 고른다. 큰 생성 이미지에 픽셀 질감을 씌운 것을 완성 스프라이트라고 부르지 않는다.
2. 한 아이템당 동물을 읽게 하는 형태 하나와 설화를 암시하는 작은 특징 하나만 남긴다. 부가 특징이 동물보다 먼저 보이면 제거하거나 본체에 통합한다.
3. 공통 검은 외곽선과 색면 밀도로 세트를 묶는다. 전부 정면의 화난 얼굴이거나 주변을 고리로 감싼 구도로 통일하지 않는다.
4. 기본적으로 5–8색에서 시작한다. 다른 재질이 꼭 필요한 경우에만 늘린다. 이 숫자를 맞추기 위해 필요한 구획을 뭉개지는 않는다.
5. 털 한 올, 비늘 한 장, 입체적인 볼근육, 별 먼지, 여러 겹 빛줄기, 가느다란 수염을 추가하지 않는다.
6. 생성 도구는 원안을 만들 때 쓰되, 최종 비교본은 네이티브 격자에서 정리한 정확한 32×32 PNG와 그 정수배 확대본으로 보여 준다. 자동 축소만 하고 끝내지 않는다.
7. 작은 크기에서 보면서 동물 구분, 본체/소품 구분, 눈·입 위치, 외곽선, 투명 여백을 확인한다. 색 수나 크기 검사만으로 화풍이 맞았다고 결론 내리지 않는다.
8. 십이지는 위엄 있는 수호신의 인상을 목표로 한다(2026-10-24 사용자 수정). 짙고 불투명한 검정 경계, 안정된 자세, 이마·턱과 또렷한 눈매로 무게를 준다. 왕관·갑옷·장식·털 묘사를 늘리지 않으며, 소품은 얼굴을 가리지 않게 아래나 옆에 둔다. 단순한 그림체가 반드시 아기 동물 같은 표정을 뜻하지는 않는다.
9. 이번 십이지의 주된 외곽선은 사용자의 추가 요청에 따라 약 2 네이티브 픽셀로 굵게 잡는다. 색만 진하게 바꾸지 말고 실제 선폭을 늘린다. 내부 눈·입과 색면은 보존하고, 뿔·귀·팔다리 사이의 빈 공간과 캔버스의 투명 여백은 유지한다. 이는 이 세트의 선택이며 모든 바닐라 아이템이 2픽셀 선이라는 관찰은 아니다.

## 이번 관찰을 적용한 산출물

`previews/zodiac-v2/`에 새 원안 12개와 직접 정리한 32×32 PNG 12개를 저장했다. `pixels.json`에 최종 픽셀 배치와 아이콘별 수정 내역을 남겼다. 5배/1배 및 어두운 배경 4배/1배 비교표로 형태와 겹침을 확인했으며, 출력 12개가 모두 32×32·5–7색·알파 0/255인 것을 검사했다. 내장 이미지 생성 프롬프트는 같은 폴더의 `prompts.json`에 기록했다. 화풍의 최종 선택은 사용자 검토 사항이며 게임 내 적용 검증은 수행하지 않았다.

후속 수정은 `previews/zodiac-v3/`에 저장했다. 외곽선을 깊은 검정으로 바꾸고, 산군은 넓은 이마·턱과 절제된 눈매로, 토끼는 드러난 얼굴과 아랫배의 작은 간으로 재구성했다. 나머지 열 종도 기존 격자에서 시선과 명도 구획을 수정했다. 산군·토끼의 수정 생성 프롬프트와 전 아이콘의 네이티브 수정 기록을 함께 남겼으며, 2차 그림은 비교용으로 보존한다.

윤곽선 두께를 늘린 후속본은 `previews/zodiac-v4/`에 저장했다. 편집 가능한 3차 네이티브 격자에서 바깥 실루엣에 검정 1픽셀을 보강했다. 기존 불투명 픽셀의 색과 위치, 내부 구멍, 1픽셀 캔버스 여백을 보존했다. `zodiac-comparison.png`는 3차와 4차를 같은 배율로 나란히 보여 주며, `validation.json`은 아이콘별 추가 검정 픽셀 수와 보존 검사를 기록한다. 이후 사용자가 적용을 요청하여 12개를 `resources/gfx/items/collectibles/`에 복사하고 각 ItemData의 `gfx`에 연결했다. 효과 구현 상태는 그림 적용과 별개다.
