# 아이작 아이템 스프라이트 관찰 기록

2026-10-24. 바닐라 24개, Epiphany 12개, Auri 11개, Astro Items 12개, 이 프로젝트 6개를 실제 PNG로 확인했다. 각 그림을 원래 크기와 정수 4배 최근접 확대본으로 함께 보았다. 아래 수치는 이 표본의 관찰값이며 게임 전체의 의무 규격이나 모드 전체의 평가가 아니다.

다른 아이템에 재사용할 입력 양식과 이미지 편집 프롬프트는 [아이작 리스프라이트 프롬프트](isaac_resprite_prompt.md)에 정리했다. 관찰값과 사용자가 선택한 굵은 외곽선 기준을 구분하여 적용한다.

## 무엇을 잘못 그렸는가

폐기한 첫 십이지 시안은 32픽셀 아이템이 아니라 픽셀처럼 보이는 큰 동물 초상화였다. 털의 여러 단계 음영, 가늘고 긴 표정선, 입체적인 뿔, 손과 소품, 동물을 두르는 능력 장식이 함께 들어갔다. 큰 사각형 픽셀을 보이게 하는 것만으로 아이작 스프라이트가 되지 않는다. 최종 크기에서 쓸 수 없는 정보는 먼저 빼야 한다.

## 우리 모드의 기준

### 최종 적용과 후속 수정 기준 — 2026-10-24

[최종 선택 기록](previews/resprite-final/selection.json)에 47종의 런타임 경로, 원본 Git 리비전, 원본·적용본 해시와 선택 이유를 남겼다. 티르핑·봉인된 마검·경구형 스테로이드·적사단지는 사용자의 최종 지시대로 원본을 유지한다. 나머지는 이전 검토에서 선택한 상태를 적용하여 19종이 변경됐고 28종은 원본과 바이트 단위로 같다. 폐기한 중간 시안과 중복 아이콘은 정리했고, [최종 모음과 원본 비교](previews/resprite-final/README.md)는 실제 런타임 PNG와 Git 원본으로 재생성한다.

일반적인 수정은 런타임 원본에서 시작하며, 사용자가 이전 시안을 선택하거나 완전 재설계를 명시한 경우에만 그 지시를 따른다. 언급 없는 아이템은 원본을 유지하고, 나머지 검토본을 승인한 이후의 부분 수정에서는 승인된 선택을 보존한다. 새 그림은 빈 32×32 격자부터 작성한다. 직접 좌표로 그린 사실이나 규격 검사는 품질의 증거가 아니며, 검신·손잡이의 비율과 축, 평행선, 내부 틈, 겹침을 실제 크기에서 확인해야 한다. 이번 두 마검의 새 시안은 채택되지 않았다.

사용자가 명시적으로 요청한 바닐라 재사용은 별도로 구분한다. 마이너스 네 종은 `trinket_145_perfection.png`의 종이·윤곽·붉은 원을 보존하고 점수만 수정했다. 기존 A+의 획과 그림자를 원 안쪽 행별로 지운 뒤, 4×6 글자와 1~2픽셀 굵기의 획을 배치했다. 중앙 사각형만 지우면 바깥 x=12의 획이 남을 수 있으므로 전체 글자 영역을 확인한다. 편측 무시는 `001.000_player.anm2`의 `HeadDown` head 레이어에 해당하는 `character_001_isaac.png`의 (0,0,32,32) 프레임에서 얼굴 오른쪽 절반을 사용했다. 양면 동전은 우리 원본의 조커 실루엣을 보존했고, 바닐라 `ui_cardfronts.anm2`의 `22_TheJoker` 프레임 (64,96,16,24)은 식별 참고로 확인했다. 이는 다른 모드 그림을 복제하는 일반 허가가 아니다.

양은 비스듬한 전신 구도로 둥근 양털 몸통·짙은 얼굴·처진 귀·짧은 다리를 드러냈다. 개는 정면 진돗개로, [연합뉴스TV 백구 사진](https://www.yonhapnewstv.co.kr/news/MYH20180102006900038)과 [FCI 표준](https://www.fci.be/Nomenclature/Standards/334g05-en.pdf)을 관찰한 뒤 중간 크기의 곧은 귀, 작은 눈, 코 쪽으로 좁아지는 볼을 반영했다. 목걸이와 해·달 표식을 제거하고 낮은 눈매와 넓은 턱으로 인상을 수정했다. 참고 사진은 저장소나 패키지에 포함하지 않는다.

추가로 바닐라 `collectibles_013_thevirus.png`, `collectibles_014_roidrage.png`, `collectibles_182_sacredheart.png`와 Epiphany `wooden_stake.png`, Auri `collectibles_auri_techeye.png`를 실제 크기와 4배로 확인했다. 주사기는 금속·유리의 잔선보다 검은 경계와 약액의 한 색 덩어리가 먼저 읽힌다. 불꽃은 입체 그라데이션 없이 노랑·주황 색면과 검은 경계로 분리된다. 적용한 주사형은 원본 비율과 노란 약액을 유지했고, 벨트는 원본 RGB에 공통값 최대 +8만 더해 검정 경계와 알파를 보존했다. SOFLAM과 진실된 눈은 잔선·과장된 형태보다 원본 구성이 낫다는 사용자 판단에 따라 원본을 유지한다.

### 전체 아이콘 리스프라이트 검토 — 2026-10-24

47종 비교 작업에 앞서 바닐라 `collectibles_169_polyphemus.png`, `collectibles_182_sacredheart.png`, `collectibles_145_guppyshead.png`, Epiphany의 `wooden_stake.png`, `broken_halo.png`, Auri의 `collectibles_auri_techeye.png`, `collectibles_auri_magehat.png`를 실제 크기와 4배 최근접 확대로 다시 확인했다. 눈은 검은 동공·흰 반사점·회색 테두리의 큰 구획으로, 말뚝은 갈색 두 면과 사선 윤곽으로, 기술 눈은 어두운 본체 안의 붉은 한 점으로 구별된다. 잘린 후광의 빈틈과 모자 챙의 겹침도 작은 크기에서 남는다. 따라서 이번 무기·안경·가위는 음영보다 손잡이·렌즈·고리의 빈틈을 우선하며, 불꽃·시간 계열은 발광을 단단한 색면으로 정리한다.

위 참고 원본과 확대표는 저장소 밖에 보관했다. 프로젝트의 `zodiac-v4/icons/05-dragon.png`, `03-tiger.png`는 굵은 경계와 색면 밀도의 참고이며, 동물 형상을 다른 물건에 옮기지 않는다. 전체 비교 기준은 최종 `selection.json`에 기록된 변경 전 Git 리비전의 런타임 PNG다.

조사 당시 교체 전 `resources/gfx/items/collectibles/dragon.png`는 32×32, 불투명 10색이었다. 정면의 길쭉한 청색 얼굴, 금색 뿔과 수염, 밝은 코의 작은 면이 정체성이다. 눈썹·털·비늘의 입체 묘사는 거의 없다. 이후 해당 런타임 파일에는 승인된 4차 그림을 적용했으므로 이 수치를 현재 파일의 측정값으로 사용하지 않는다. `azure_dragon.png`는 조사 당시 훨씬 촘촘한 별도 길동무 그림(부분 알파, 234개의 RGBA 조합)이었으므로 이번 기준으로 쓰지 않는다.

추가로 `kronos.png`, `real_eyes.png`, `ar_glasses.png`, `severed_oath.png`를 확인했다. 물체 하나와 명확한 겹침만으로 아이템이 읽힌다. 이들의 형상을 동물 그림에 복사할 이유는 없고, 밀도와 중심 형태만 참고한다.

## 십이지 재설계에 적용할 규칙

1. 실제 32×32 안에서 형태를 고른다. 큰 생성 이미지에 픽셀 질감을 씌운 것을 완성 스프라이트라고 부르지 않는다.
2. 한 아이템당 동물을 읽게 하는 형태 하나와 설화를 암시하는 작은 특징 하나만 남긴다. 부가 특징이 동물보다 먼저 보이면 제거하거나 본체에 통합한다.
3. 공통 검은 외곽선과 색면 밀도로 세트를 묶는다. 전부 정면의 화난 얼굴이거나 주변을 고리로 감싼 구도로 통일하지 않는다.
4. 기본적으로 5–8색에서 시작한다. 다른 재질이 꼭 필요한 경우에만 늘린다. 이 숫자를 맞추기 위해 필요한 구획을 뭉개지는 않는다.
5. 털 한 올, 비늘 한 장, 입체적인 볼근육, 별 먼지, 여러 겹 빛줄기, 가느다란 수염을 추가하지 않는다.
6. 생성 도구는 원안을 만들 때 쓰되, 최종 비교본은 네이티브 격자에서 정리한 정확한 32×32 PNG와 그 정수배 확대본으로 보여 준다. 자동 축소만 하고 끝내지 않는다.
