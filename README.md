소개 (KR)
--------------------------------------------------
아이작에 "소라고둥의 축복" 업그레이드 시스템을 추가합니다. Magic Conch의 대답(긍정·중립·부정)에 따라 기존 아이템이 전용 연출과 함께 이 모드의 아이템으로 진화하고, 언어/HUD/EID를 자동 적용하며, 스폰과 연출을 세밀하게 설정할 수 있습니다.

- 아이템 업그레이드 연출: Before → Morph → After로 자연스럽게 연결
- 진화 미리보기: 진화할 수 있는 아이템 가까이 가면 소라고둥 대답별 결과가 가지처럼 펼쳐짐(거리는 MCM에서 조절)
- 다국어 지원: 한국어/영어/우리말 HUD·EID(설정으로 언어 고정 가능, 한글날에는 한국어를 고르면 우리말로 표시)
- 자연 스폰 토글: MCM에서 모드 수집품·장신구의 자연 스폰 ON/OFF(기본 OFF)
- 소리 설정: MCM에서 효과음과 빗소리 크기 조절
- Mod Config Menu 호환

Overview (EN)
--------------------------------------------------
Adds a polished "Conch’s Blessing" upgrade system. Depending on the Magic Conch's answer (positive, neutral or negative), existing items evolve into this mod's items with bespoke visuals, language-aware HUD/EID, and flexible spawn and presentation settings.

- Upgrade Sequence: Before → Morph → After
- Evolution Preview: near an item that can evolve, its results for each Conch answer branch out above it (range set in MCM)
- Multi-language HUD/EID: Korean, English and 우리말 (native-Korean wording); optionally force a language
- Natural Spawn Toggles for mod collectibles and trinkets via MCM (default OFF)
- Sound Settings: effect and rain volume via MCM
- Compatible with Mod Config Menu
